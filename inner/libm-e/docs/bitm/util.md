# Utilities

Utility functions for counting and reversing bits/bytes.

## Functions

- `COUNT bitcount(const unsigned char* bytes, size_t len)`: Counts set bits.
- `COUNT bytecount(const unsigned char* bytes, size_t len)`: Counts bytes.
- `COUNT bitreverse(const unsigned char* in, unsigned char* out, size_t len)`: Reverses bits.
- `COUNT bytereverse(const unsigned char* in, unsigned char* out, size_t len)`: Reverses bytes.
