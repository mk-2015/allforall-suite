# Rotate

Bitwise rotation functions for various integer sizes.

## Functions

### 8-bit
- `uint8_t rotl8(uint8_t value, unsigned int shift)`: Left rotate.
- `uint8_t rotr8(uint8_t value, unsigned int shift)`: Right rotate.

### 16-bit
- `uint16_t rotl16(uint16_t value, unsigned int shift)`: Left rotate.
- `uint16_t rotr16(uint16_t value, unsigned int shift)`: Right rotate.

### 32-bit
- `uint32_t rotl32(uint32_t value, unsigned int shift)`: Left rotate.
- `uint32_t rotr32(uint32_t value, unsigned int shift)`: Right rotate.

### 64-bit
- `uint64_t rotl64(uint64_t value, unsigned int shift)`: Left rotate.
- `uint64_t rotr64(uint64_t value, unsigned int shift)`: Right rotate.
