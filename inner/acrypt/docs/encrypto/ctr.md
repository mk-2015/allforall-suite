# AES-CTR Mode (`acry/modes/ctr.h`)

Counter mode, built on [`acry/aes.h`](aes.md). A keystream is generated by encrypting successive counter blocks and XORed with the input — **encryption and decryption are the exact same operation**. No padding: output length always equals input length.

> **Security notes:**
> - You must **never reuse a `(key, nonce_counter)` pair** across two different messages. Doing so lets an attacker XOR the two ciphertexts together to recover the XOR of the two plaintexts — a catastrophic, total break of confidentiality (the classic two-time-pad problem). A common safe pattern: a random or monotonically increasing nonce in the first bytes of the counter block, unique per message under a given key.
> - Like CBC, plain CTR provides **no integrity/authenticity check**. Unlike CBC, an attacker can flip any bit of ciphertext to flip the corresponding bit of plaintext, silently and undetectably. Pair it with a MAC if you need tamper detection.

## Functions

### `AES_CTR_crypt`

```c
int AES_CTR_crypt(const AES_HANDLE *ctx, const acry_u8 nonce_counter[AES_BLOCK_SIZE],
                   const acry_u8 *data, size_t len,
                   acry_u8 **out, size_t *out_len);
```

`nonce_counter` is the 16-byte starting counter block; it's incremented internally as a big-endian 128-bit integer for each successive 16-byte chunk of `data`, but the caller chooses the starting value. On success returns `0` and writes a newly allocated buffer to `*out` (`*out_len` always equals `len`; caller must `free`). Returns `-1` on allocation failure.

Because encryption and decryption are identical, call this the same way in both directions — just pass the same `nonce_counter` you used to encrypt.

## Example Usage

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <acry/aes.h>
#include <acry/modes/ctr.h>

int main(void) {
    acry_u8 key[16] = { /* ... */ };
    acry_u8 nonce_counter[16] = { /* unique per message under this key */ };
    const char *msg = "Attack at dawn.";

    AES_HANDLE ctx = AES_HANDLE_open(key, sizeof(key));

    acry_u8 *ct; size_t ct_len;
    AES_CTR_crypt(&ctx, nonce_counter, (const acry_u8*)msg, strlen(msg), &ct, &ct_len);

    acry_u8 *pt; size_t pt_len;
    AES_CTR_crypt(&ctx, nonce_counter, ct, ct_len, &pt, &pt_len); /* same call decrypts */
    /* pt[0..pt_len) == "Attack at dawn." */

    free(ct);
    free(pt);
    AES_HANDLE_close(ctx);
    return 0;
}
```
