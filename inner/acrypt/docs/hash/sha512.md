# SHA-512 Module (`acry/hash/sha512.h`)

Implements the SHA-512 cryptographic hash function (FIPS 180-4), producing a 512-bit (64-byte) digest. Supports both stateful, streaming handles and quick one-shot functions.

## Functions

### `SHA512_HANDLE_open`

```c
SHA512_HANDLE SHA512_HANDLE_open(void);
```

Initializes a new SHA-512 context with the standard initial hash state.

### `SHA512_update`

```c
void SHA512_update(SHA512_HANDLE *ctx, const void *data, size_t len);
```

Feeds `len` bytes of `data` into the hash. Can be called any number of times with arbitrarily sized chunks — internally buffers partial blocks, so streaming input (e.g. reading a file incrementally) works correctly.

### `SHA512_final`

```c
void SHA512_final(acry_u8 *digest, SHA512_HANDLE *ctx);
```

Finalizes the hash (applies padding and the 128-bit length suffix) and writes the `ACRY_SHA512_DIGEST_SIZE` (64-byte) digest into the caller-supplied `digest` buffer. After calling this, the context should not be reused for further `SHA512_update` calls.

### `SHA512_HANDLE_close`

```c
int SHA512_HANDLE_close(SHA512_HANDLE ctx);
```

Releases the handle. Returns `0` on success.

### `SHA512_bytes_NO_HANDLE`

```c
acry_u8* SHA512_bytes_NO_HANDLE(const void *data, size_t len);
```

One-shot hashing without managing handle lifecycle. Returns a newly allocated `ACRY_SHA512_DIGEST_SIZE`-byte buffer (caller must `free`), or `NULL` on allocation failure.

## Example Usage

```c
#include <stdio.h>
#include <stdlib.h>
#include <acry/hash/sha512.h>

int main(void) {
    // One-shot
    acry_u8 *digest = SHA512_bytes_NO_HANDLE("abc", 3);
    for (size_t i = 0; i < ACRY_SHA512_DIGEST_SIZE; i++) printf("%02x", digest[i]);
    printf("\n");
    // ddaf35a193617abacc417349ae20413112e6fa4e89a97ea20a9eeee64b55d39
    // a2192992a274fc1a836ba3c23a3feebbd454d4423643ce80e2a9ac94fa54ca49
    free(digest);

    // Streaming
    SHA512_HANDLE ctx = SHA512_HANDLE_open();
    SHA512_update(&ctx, "ab", 2);
    SHA512_update(&ctx, "c", 1);
    acry_u8 out[ACRY_SHA512_DIGEST_SIZE];
    SHA512_final(out, &ctx);
    SHA512_HANDLE_close(ctx);

    return 0;
}
```
