# SHA-224 Module (`acry/hash/sha224.h`)

Implements the SHA-224 cryptographic hash function (FIPS 180-4), producing a 224-bit (28-byte) digest. SHA-224 is SHA-256 run with different initial hash values, with the final digest truncated to the first 28 of 32 bytes. Supports both stateful, streaming handles and quick one-shot functions.

## Functions

### `SHA224_HANDLE_open`

```c
SHA224_HANDLE SHA224_HANDLE_open(void);
```

Initializes a new SHA-224 context with SHA-224's initial hash state (distinct from SHA-256's).

### `SHA224_update`

```c
void SHA224_update(SHA224_HANDLE *ctx, const void *data, size_t len);
```

Feeds `len` bytes of `data` into the hash. Can be called any number of times with arbitrarily sized chunks — internally buffers partial blocks, so streaming input (e.g. reading a file incrementally) works correctly.

### `SHA224_final`

```c
void SHA224_final(acry_u8 *digest, SHA224_HANDLE *ctx);
```

Finalizes the hash (applies padding and the length suffix) and writes the `ACRY_SHA224_DIGEST_SIZE` (28-byte) digest into the caller-supplied `digest` buffer. After calling this, the context should not be reused for further `SHA224_update` calls.

### `SHA224_HANDLE_close`

```c
int SHA224_HANDLE_close(SHA224_HANDLE ctx);
```

Releases the handle. Returns `0` on success.

### `SHA224_bytes_NO_HANDLE`

```c
acry_u8* SHA224_bytes_NO_HANDLE(const void *data, size_t len);
```

One-shot hashing without managing handle lifecycle. Returns a newly allocated `ACRY_SHA224_DIGEST_SIZE`-byte buffer (caller must `free`), or `NULL` on allocation failure.

## Example Usage

```c
#include <stdio.h>
#include <stdlib.h>
#include <acry/hash/sha224.h>

int main(void) {
    // One-shot
    acry_u8 *digest = SHA224_bytes_NO_HANDLE("abc", 3);
    for (size_t i = 0; i < ACRY_SHA224_DIGEST_SIZE; i++) printf("%02x", digest[i]);
    printf("\n"); // 23097d223405d8228642a477bda255b32aadbce4bda0b3f7e36c9da
    free(digest);

    // Streaming
    SHA224_HANDLE ctx = SHA224_HANDLE_open();
    SHA224_update(&ctx, "ab", 2);
    SHA224_update(&ctx, "c", 1);
    acry_u8 out[ACRY_SHA224_DIGEST_SIZE];
    SHA224_final(out, &ctx);
    SHA224_HANDLE_close(ctx);

    return 0;
}
```
