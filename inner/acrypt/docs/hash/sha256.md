# SHA-256 Module (`acry/hash/sha256.h`)

Implements the SHA-256 cryptographic hash function (FIPS 180-4), producing a 256-bit (32-byte) digest. Supports both stateful, streaming handles and quick one-shot functions.

## Functions

### `SHA256_HANDLE_open`

```c
SHA256_HANDLE SHA256_HANDLE_open(void);
```

Initializes a new SHA-256 context with the standard initial hash state.

### `SHA256_update`

```c
void SHA256_update(SHA256_HANDLE *ctx, const void *data, size_t len);
```

Feeds `len` bytes of `data` into the hash. Can be called any number of times with arbitrarily sized chunks — internally buffers partial blocks, so streaming input (e.g. reading a file incrementally) works correctly.

### `SHA256_final`

```c
void SHA256_final(acry_u8 *digest, SHA256_HANDLE *ctx);
```

Finalizes the hash (applies padding and the length suffix) and writes the `ACRY_SHA256_DIGEST_SIZE` (32-byte) digest into the caller-supplied `digest` buffer. After calling this, the context should not be reused for further `SHA256_update` calls.

### `SHA256_HANDLE_close`

```c
int SHA256_HANDLE_close(SHA256_HANDLE ctx);
```

Releases the handle. Returns `0` on success.

### `SHA256_bytes_NO_HANDLE`

```c
acry_u8* SHA256_bytes_NO_HANDLE(const void *data, size_t len);
```

One-shot hashing without managing handle lifecycle. Returns a newly allocated `ACRY_SHA256_DIGEST_SIZE`-byte buffer (caller must `free`), or `NULL` on allocation failure.

## Example Usage

```c
#include <stdio.h>
#include <stdlib.h>
#include <acry/hash/sha256.h>

int main(void) {
    // One-shot
    acry_u8 *digest = SHA256_bytes_NO_HANDLE("abc", 3);
    for (size_t i = 0; i < ACRY_SHA256_DIGEST_SIZE; i++) printf("%02x", digest[i]);
    printf("\n"); // ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
    free(digest);

    // Streaming
    SHA256_HANDLE ctx = SHA256_HANDLE_open();
    SHA256_update(&ctx, "ab", 2);
    SHA256_update(&ctx, "c", 1);
    acry_u8 out[ACRY_SHA256_DIGEST_SIZE];
    SHA256_final(out, &ctx);
    SHA256_HANDLE_close(ctx);

    return 0;
}
```
